# GPS-VPS 手机端适配要求与任务清单

## 1. 目标

手机端作为 GPS-VPS 的数据发送端，持续获取主人手机定位，并通过 WebSocket 发送到云端中转服务器。YukiV6 主程序中的主人状态监控会作为接收端监听同一服务器，并在 `get_master_status` 工具结果中返回最新位置状态。

## 2. 对接地址

| 参数 | 默认值 | 说明 |
|------|--------|------|
| WebSocket URL | `ws://8.217.41.28:8765` | GPS-VPS 云端中转服务器地址 |
| 协议 | WebSocket | 客户端连接后直接发送文本消息 |
| 编码 | UTF-8 | JSON 字符串使用 UTF-8 编码 |
| 重连间隔 | 5 秒 | 断线、网络切换、服务器不可达后等待再重连 |
| 发送间隔 | 3 秒建议值 | 正常前台或后台持续定位时的默认发送频率 |

YukiV6 接收端可通过环境变量覆盖：

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `YUKI_GPS_VPS_SERVER_URL` | `ws://8.217.41.28:8765` | 接收端连接地址 |
| `YUKI_GPS_VPS_FETCH_TIMEOUT_SECONDS` | `5` | 调用状态工具时等待下一条位置消息的超时时间，单位秒 |
| `YUKI_GPS_VPS_STALE_SECONDS` | `300` | 超过该时间未收到定位时标记为 stale |

## 3. 消息格式

手机端每次发送一个 JSON 对象，最小必需字段如下：

```json
{
  "longitude": 114.169211,
  "latitude": 22.322653,
  "timestamp": "2026-07-24T03:19:47.991240+00:00"
}
```

### 3.1 字段要求

| 字段 | 类型 | 必需 | 示例 | 说明 |
|------|------|------|------|------|
| `longitude` | number | 是 | `114.169211` | WGS84 经度，建议保留 6 位小数 |
| `latitude` | number | 是 | `22.322653` | WGS84 纬度，建议保留 6 位小数 |
| `timestamp` | string | 是 | `2026-07-24T03:19:47.991240+00:00` | 手机端采集定位的 UTC ISO 8601 时间 |

### 3.2 可选扩展字段

当前 YukiV6 接收端会保留并使用核心字段，后续可在不破坏协议的前提下扩展以下字段：

| 字段 | 类型 | 示例 | 说明 |
|------|------|------|------|
| `accuracy` | number | `12.5` | 水平精度，单位米 |
| `altitude` | number | `42.1` | 海拔，单位米 |
| `speed` | number | `1.2` | 速度，单位 m/s |
| `bearing` | number | `180.0` | 方向角，单位度 |
| `provider` | string | `gps` | 定位来源，如 `gps`、`network`、`fused` |
| `battery` | number | `86` | 手机电量百分比 |
| `device_id` | string | `master-phone` | 设备标识，后续多设备区分使用 |

## 4. 手机端功能任务

1. WebSocket 客户端
   - 连接 `ws://8.217.41.28:8765`。
   - 连接成功后保持长连接。
   - 发送端不需要等待服务器响应。
   - 连接断开、网络切换、应用恢复前台后自动重连。

2. 定位采集
   - 国内定位优先输出 GCJ-02 坐标，便于 YukiV6 使用高德逆地理编码解析地址。
   - 如定位 SDK 只能输出 WGS84，需要在手机端转换为 GCJ-02 后再发送；境外坐标按平台原始返回处理。
   - 默认每 3 秒发送一次最新位置。
   - 当位置权限未授权、定位关闭或系统限制后台定位时，停止发送并在本地提示用户。
   - 建议过滤明显无效坐标，例如经纬度为空、`0,0` 或精度过差的数据。

3. 后台运行
   - 需要支持锁屏或后台时继续定位。
   - Android / HarmonyOS 需要前台服务或等效后台定位能力。
   - iOS 需要启用后台定位模式，并处理系统对持续定位的限制。

4. 权限申请
   - 前台定位权限。
   - 后台定位权限。
   - 网络访问权限。
   - 如平台要求，申请通知权限以展示后台定位前台服务通知。

5. 时间戳
   - `timestamp` 必须是定位采集时间，不是发送时间。
   - 使用 UTC ISO 8601 格式，带时区，例如 `2026-07-24T03:19:47.991240+00:00`。

6. 本地状态展示
   - 显示 WebSocket 连接状态。
   - 显示最近一次发送成功的经纬度和时间。
   - 显示定位权限、定位开关、后台运行权限是否满足。

## 5. 发送策略细节

| 场景 | 建议行为 |
|------|----------|
| 正常移动 | 每 3 秒发送一次 |
| 静止状态 | 可保持 3 秒发送，或放宽到 10-30 秒发送 |
| 网络断开 | 缓存最新一条定位即可，不需要批量补发 |
| WebSocket 断开 | 5 秒后重连，重连成功后继续发送最新定位 |
| 定位精度差 | 可发送 `accuracy` 字段，或跳过明显异常数据 |
| 电量低 | 可降低发送频率，但不建议完全停止，除非用户明确关闭 |

## 6. 与 YukiV6 接收端的状态对应

YukiV6 主人状态监控返回的 `gps` 字段结构如下：

```json
{
  "enabled": true,
  "connected": true,
  "stale": false,
  "server_url": "ws://8.217.41.28:8765",
  "location": {
    "longitude": 114.169211,
    "latitude": 22.322653,
    "timestamp": "2026-07-24T03:19:47.991240+00:00",
    "received_at": "2026-07-24T11:19:48.100000+08:00",
    "address": {
      "formatted_address": "香港特别行政区油尖旺区...",
      "country": "中国",
      "province": "香港特别行政区",
      "city": "香港特别行政区",
      "district": "油尖旺区",
      "adcode": "810005",
      "citycode": "1852",
      "street": "...",
      "street_number": "...",
      "neighborhood": "..."
    }
  },
  "location_age_seconds": 1.2,
  "last_error": null
}
```

字段含义：

| 字段 | 说明 |
|------|------|
| `enabled` | 接收端是否安装了 `websockets` 依赖 |
| `connected` | 最近一次接收是否无错误 |
| `stale` | 最新定位是否超过 `YUKI_GPS_VPS_STALE_SECONDS` 未更新 |
| `server_url` | 当前接收端连接的服务器地址 |
| `location` | 最近一次收到的位置数据 |
| `location_age_seconds` | 最新位置距当前时间的秒数 |
| `last_error` | 最近一次连接或解析错误 |

## 7. 联调步骤

1. 确认云端服务运行：`ws://8.217.41.28:8765`。
2. 启动 YukiV6 主程序，确认主人状态监控服务已启动。
3. 手机端连接 WebSocket 并持续发送定位 JSON。
4. 在手机端仍在发送时调用 `get_master_status`，YukiV6 会短连接等待下一条位置消息并更新 `gps.location`。
5. 停止手机端发送后再次调用 `get_master_status`，确认等待超过 `YUKI_GPS_VPS_FETCH_TIMEOUT_SECONDS` 后返回缓存位置和超时错误。
6. 停止手机端发送超过 300 秒后，确认 `gps.stale` 变为 `true`。

## 8. 验收标准

- 手机端可连接云端 WebSocket 并持续发送 JSON 定位。
- YukiV6 `get_master_status` 可看到最新 `gps.location`。
- 断线后手机端能自动重连。
- 手机锁屏或后台运行时仍能按平台允许的方式更新定位。
- 未授权定位、定位关闭、网络不可用时，手机端有明确状态提示。
- 经纬度、时间戳格式符合本文件要求。
