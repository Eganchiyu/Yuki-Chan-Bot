# Hy-Memory 技术文档

## 1. 概述

Hy-Memory 是腾讯混元（Tencent Hunyuan）于 2026年5月28日正式发布的 AI Agent 记忆框架插件。

- 官方标语："记住一次，随处同行"（Remember Once, Accompany Everywhere）
- 定位：专为 OpenClaw 等长期协作型 AI Agent 设计的"第二大脑"记忆插件
- 核心理念：将用户的长期偏好、事实、画像和意图沉淀成一份可共享的记忆资产
- 官网：https://memory.hunyuan.tencent.com/

---

## 2. 三大核心技术

### 2.1 六层记忆框架（6-Layer Memory Framework）

记忆从原始对话逐层演化为结构化认知：

| 层级 | 名称     | 英文标识   | 加工路径  | 说明 |
|------|----------|------------|-----------|------|
| L1   | 原始痕迹 | RAW        | System1   | 保留对话、行为和上下文，作为后续加工的原料 |
| L2   | 原子事实 | FACT       | System1   | 把零散表达压成可检索、可更新、可合并的事实片段 |
| L3   | 身份画像 | IDENTITY   | System1   | 稳定的长期偏好、特质和人设画像，跨Agent复用 |
| L4   | 会话摘要 | SUMMARY    | System1   | 现场压一句长会话精华 |
| L5   | 心智模型 | SCHEMA     | System2   | 从行为里抽出认知框架（异步沉淀） |
| L6   | 前瞻意图 | INTENTION  | System2   | 异步沉淀的下一步意图预测 |

### 2.2 System1 / System2 双路径系统

受认知科学启发的双系统架构：

**System1 — 在线快路径（ms级闭环）**
- 用户开口的同一秒就把记忆种下去
- 每条对话必写 L1 原始痕迹
- 注意力闸门判断是否值得加工
- 实时抽取 L2 原子事实、L3 身份画像
- 现场写 L4 会话摘要

**System2 — 后台慢整理（秒到分钟级）**
- "睡眠回放"机制，把 System1 种下的材料长成认知
- 异步沉淀 L5 心智模型
- 异步沉淀 L6 前瞻意图

### 2.3 演化链（Evolution Chain）

记忆不是堆积，而是演化。核心机制：

- **supersedes 指针**：写入时用指针把记忆串成因果链
- 命中链上任意一条，整条"态度演变"自动跟出
- 冲突处理：新旧偏好不并存，旧的淡化，新的固化
- 合并去重：同一类事实归并到一条，不重复堆

**演化5步示例（"东京寿司"场景）：**

1. **L1 RAW** — 原话落地："上次去东京吃了寿司，很好"
2. **L2 FACT** — 事实抽取：去过东京 / 喜欢寿司
3. **L2 FACT** — 合并去重：与历史"喜欢日料"合并（喜欢寿司 ⊂ 喜欢日料）
4. **L5 SCHEMA** — 冲突处理：旧画像"偏甜口" vs 新输入"喜欢咸鲜" → 刷新为咸鲜
5. **L3 IDENTITY** — 画像沉淀：饮食偏好定为"海鲜系日料"

**supersedes 因果链示例（独立民谣创作人场景）：**

| 记忆 | 时间 | 态度 | 链接 |
|------|------|------|------|
| 记忆A | 去年春 | 拥抱首次线上发行，态度积极 | — |
| 记忆B | 去年夏 | 失望，Spotify算法消解叙事型创作 | supersedes A |
| 记忆C | 去年秋 | 决裂，主动下架Spotify，转Bandcamp | supersedes B |
| 记忆D | 上月 | 重建，重新评估分发策略 | supersedes C |

命中链上任意一条，整条"态度演变"自动跟出——这是向量召回永远做不到的事。

## 7. 接入方式

Hy-Memory 作为 OpenClaw 的共享记忆插件接入：

1. **记忆进入内核** — 把用户与 Agent 的长期交互交给 Hy-Memory 分层沉淀
2. **框架持续整理** — System1 负责即时响应，System2 在后台把碎片变成稳定画像
3. **接入 OpenClaw** — OpenClaw 一键接入 Hy-Memory，原生记忆能力升级为专业级长期记忆

OpenClaw 原生具备基础的对话记忆能力，可覆盖单次会话内的上下文。接入 Hy-Memory 后，记忆从"会话级线性追加"升级为"可演化结构化沉淀"——长期偏好、事实、画像与意图被持续整理与去重，准确率与时效性显著提升。

## 8. 与现有方案对比

| 特性 | 普通记忆系统 | Hy-Memory |
|------|------------|-----------|
| 记忆增长 | 越用越乱，噪声堆积 | 越用越像你，持续演化 |
| 冲突处理 | 新旧偏好并存 | 矛盾不并存，旧的淡化新的固化 |
| 事实管理 | 同类事实反复堆叠 | 合并去重，一条最新 |
| 召回能力 | 仅向量相似度 | supersedes 因果链 + 向量召回 |
| 跨Agent | 不支持 | 身份画像跨Agent复用 |
